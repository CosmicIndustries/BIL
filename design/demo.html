SUES Slot Syntax

Human-typed compact input format: ACT:<speech_act> AGT:<agent> PRED:<predicate> OBJ:<object> STYLE:<style+style> OUT:<format>

SlotDescriptionExample values
ACTSpeech act!askdo !do ?ask whyshow say
AGTAgent/doer@self @you @we
PREDPredicate/actionpartmake workagain bettermake
OBJObject/themecodedo partnet infobits
